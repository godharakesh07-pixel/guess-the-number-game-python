# 🎯 Guess the Number Game

## 📖 About
This is my first Python mini project.

The program generates a random number between 1 and 100, and the player keeps guessing until the correct number is found.

## 🚀 Features
- Random number generation
- User input
- While loop
- If-Else conditions
- Attempt counter

## 🛠️ Technologies Used
- Python 3

## ▶️ How to Run
1. Clone the repository.
2. Run:
   python guess_the_number_game.py
